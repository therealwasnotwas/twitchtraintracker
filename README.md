<h1>Twitch Train Tracker</h1></P>
Purpose:</P>

A program to report a twitch users time spent in each live streams within a twitch raid train.<br>
What it does:</P>

This program will give a report giving a breakdown and importantly the time spent within individual streams for a twitch user. It does this by analysing log file output for the twitch stream or streams and parsing the data for the twitch user or users specified quickly and into an easily readable format.</P>

As an example this data can then be exported and used to provide a table or list of the most supportive users or DJ's within a series of live twitch broadcasts.</P>

It is particulary useful for Twitch raid train organisers or teams looking for an accurate way of reporting on which of their members have been supporting the twitch raid train's they organise and the twitch trains members in the community while playing on the twitch train.</P>

Supported Platforms:</P>

Windows (64 bit) (.EXE)<br>
Mac (Intel/Apple Silicon) (.DMG)</P>
Upcoming Features:</P>

Web Conversion - Upload log files for a report directly on the web or for download to your local machine<br>
Twitch Train Tracker Bot - Add the Twitch Train Tracker bot to your twitch stream and raid trains. It will collect the required data to produce a report for you via the web portal. (Note: It does not need to be modded)<br>
